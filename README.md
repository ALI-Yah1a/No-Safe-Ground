# No Safe Ground
- No safe ground is a 2D platformer game with 5 levels. To complete all the levels you should go to the endpoint to win each level!
- The primary challenge is to avoid the fire and collect fruits as much as you can.
# IMPORTANT NOTE
- This is the first version of the game, it has some incomplete sections (e.g., levels), and there is still only 2 levels left.
- This week we finished the main menu, player scene, pickups, and 3 full levels. 
## How To Run The Game?
- To run the game you should open the itch.io link, then click the button "Run Game". So simple.
## How To Play The Game?
- To play the game correctly, you should click the "START" button in the main menu after running the game. Then select the one of the 3 levels.
- The only way to complete the level is by reaching the endpoint of each level. Also, it is optional to collect fruits, there is no required amount.
- You must avoid the fire, or you would die if you got damaged 4 times.
  
## Controllers
- Movement is controlled using A and D or the ← and → arrow keys to move the character horizontally across the level.
- The player can jump using the spacebar or W button, you can also double press it to double jump.
- Using ESC for pause.
